## Part 2 — Which Portals, and What Each One Is For

Don't use all portals equally. Give each a job.

| Portal | Its job | Effort |
| ------ | ------- | ------ |
| **LinkedIn** | #1 — referrals + recruiter inbound. Your relationship engine | Daily |
| **Instahyre** | #2 — passive inbound. Set up once, recruiters reach you | Check 2x/week |
| **Naukri** | #3 — volume apply + inbound recruiter calls | Daily |
| **Wellfound** | Optional — funded startups only | Weekly browse |
| **Indeed** | Skip — mostly duplicates | — |

How the funnel splits:
- **Inbound (work while you sleep):** LinkedIn "Open to Work" + Instahyre
- **Outbound (you apply):** Naukri + Wellfound
- **Referrals (highest conversion):** LinkedIn DMs

> Portals are your **discovery** layer. The referral is your **entry** layer. For every interesting role, find a person there first instead of cold-applying.

## Part 3 — How to Search (so you don't drown)

Use the curated search terms in **Part 3A** below. Quick version — on LinkedIn Jobs and Naukri:

```
(".NET" OR "C#" OR "ASP.NET") AND ("React" OR "Full Stack")
```

Filters every time:
- **Date posted: Past 24 hours / Past week** — apply before 200 applicants pile in
- **Experience: Associate / Mid (2–4 yrs)**
- **Sort by: Most recent** (not "most relevant")
- Skip roles already showing "200+ applicants"

Set alerts so jobs come to you:
- **LinkedIn:** save the Boolean search → toggle alert ON
- **Naukri:** 2–3 alerts — `.NET Developer`, `Software Engineer C#`, `Full Stack Developer`
- **Instahyre:** set preferences once
- **Follow** your 25–30 shortlisted companies on LinkedIn so postings hit your feed

## Part 3A — Curated Search Terms (copy-paste)

Product companies use different titles for the *same* SDE-1 level. Search all of them.

### Role-title keywords

| Term | Who uses it / what it means |
| ---- | --------------------------- |
| **Software Engineer** | Universal, most common |
| **Software Development Engineer** / **SDE** | Amazon, Flipkart, Atlassian, most product cos |
| **SDE 1** / **SDE I** / **SDE-1** | Your exact level |
| **SDE 2** / **SDE II** | Stretch — apply if 3+ yrs listed; 2.5 sometimes qualifies |
| **Member of Technical Staff** / **MTS** | Salesforce, Nutanix, VMware, Druva, Cohesity, Oracle |
| **MTS 1** / **MTS-1** / **Software Engineer (MTS)** | Level-1 variant of above |
| **Software Engineer II** | Microsoft's SDE-1 equivalent |
| **Associate Software Engineer** | Some cos use for 1–3 yrs |
| **Application Developer** | Enterprise / fintech (Goldman, MS, banks) |
| **Product Engineer** | Startups / dev-tools (Postman, Razorpay) |

### Stack / specialization keywords (combine with the above)

| Term | Use when |
| ---- | -------- |
| **.NET Developer** | Strongest signal for you |
| **.NET Core Developer** | Modern .NET roles |
| **C# Developer** | Backend-focused |
| **ASP.NET Developer** / **ASP.NET Core** | Web backend |
| **Backend Developer** / **Backend Engineer** | Your strongest depth |
| **Full Stack Developer** / **Full Stack Engineer** | .NET + React covers this |
| **Dotnet Fullstack** | Common Naukri phrasing ("dotnet" one word) |
| **Software Engineer - Backend** | Combined |

### Ready-to-paste Boolean searches

**LinkedIn — broad net (title search):**
```
("Software Engineer" OR "SDE" OR "Member of Technical Staff" OR "MTS" OR ".NET Developer" OR "Backend Engineer" OR "Full Stack Engineer")
```

**LinkedIn — stack-targeted (fewer, more relevant):**
```
(".NET" OR "C#" OR "ASP.NET" OR "dotnet") AND ("Software Engineer" OR "SDE" OR "Backend" OR "Full Stack")
```

**Naukri — run as 2–3 separate alerts (keep terms simple):**
```
.NET Developer
Software Engineer C#
Dotnet Fullstack Developer
SDE Backend
```

### Level filters — pair with every search

- **Experience:** `2–4 years` (catches SDE-1 and some SDE-2)
- ✅ **Search:** SDE, SDE-1, SDE-2, MTS, MTS-1, Software Engineer (II), .NET Developer, Backend Engineer, Full Stack Engineer, Application Developer, Product Engineer
- ❌ **Skip:** SDE-3, SMTS (Senior MTS), Senior / Lead / Staff / Principal, Engineering Manager, Architect, Tech Lead — these are 5+ yrs
- ⚠️ "Software Engineer" alone also returns senior roles — always add the experience filter

## Part 4 — Your Daily Routine (~30–45 min on the hunt)

Run this every weekday. Applications take 2–4 weeks to convert, so start now and stay consistent.

### Morning (15 min)
1. Scan LinkedIn + Naukri alert emails.
2. For each fresh, good-fit role: **find someone at the company on LinkedIn and send a referral DM** (don't cold-apply).
3. Reply to any recruiter message within a few hours — speed matters.

### Evening (20 min)
4. Apply to **5–10 filtered roles** on Naukri (product companies, posted <1 week).
5. Send **3–5 referral DMs** total using the template below.
6. Log everything in your tracker (Part 5).

### Plus, in parallel (the prep track — 1.5–2 hrs)
7. **2 DSA problems/day in C#** (NeetCode 150 / LeetCode). Non-negotiable for product companies.
8. Weekend: 3 DSA + 1 mock interview + review .NET/system-design concepts.

### Weekly upkeep
- Refresh Naukri profile (bumps you in recruiter search).
- Browse Wellfound + Instahyre inbound.
- Post 1 short .NET/Azure note on LinkedIn (keeps you visible to recruiters).

### Referral DM template
> Hi [Name], I'm a Software Engineer with 2.5 years at GlobalLogic working on Microsoft projects — C# .NET Core, Azure, React/TypeScript. I'm exploring opportunities at [Company] and noticed you work there. Would you be open to referring me for [specific role ID/title]? Happy to share my resume. Thanks!

Keep it short, specific, name the role. Never send a generic "I'm looking for opportunities."

## Part 5 — Track Everything (one sheet)

Without this you'll lose count and never follow up. Make a simple sheet with these columns:

```
Company | List (Top/High) | Role + ID | Stack match (1-5) | Referral? (who) | Date applied | Channel | Status | Follow-up date | Notes
```

- Follow up on a referral DM in **5–7 days** if no reply.
- "Status" flow: Applied → Referred → Recruiter call → OA → Tech rounds → HM → Offer.

## Part 6 — Positioning (fix once, Week 1)

You're tagged "Frontend Developer" but your resume is backend/.NET — that mismatch costs you calls.

- Naukri: update headline, key skills, IT skills, summary. Upload the **.NET-heavy** resume PDF.
- Set Naukri to **"Active — Looking for a job"** (not "open to opportunities").
- LinkedIn headline: `Software Engineer | C# .NET Core | Azure | React TypeScript`
- Turn on LinkedIn **"Open to Work"** (recruiters-only).

Roles to apply for (all three, not just one): **Software Engineer / SDE-1**, **Backend Developer (.NET)**, **Full Stack Developer**.

## Part 7 — Quick Reference: Interview & Pay

**Rounds:** Online Assessment (DSA) → Tech Round 1 (DSA + C#/.NET fundamentals: async/await, DI lifecycle, EF change tracking, middleware) → Tech Round 2 / LLD (design patterns: Repository, Factory, Strategy) → Hiring Manager (walk through your licensing analytics backend in 5 min) → HR.

**"Why are you leaving?"** — frame as growing *toward* something:
> I've had a great 2.5 years at GlobalLogic building production systems for Microsoft. Now I'm looking for a product-oriented environment where I can work on the core product, see direct user impact, and grow into system design ownership.
Never say: better pay / bored / service companies are bad.

**Pay benchmarks (2.5 YOE, .NET/full-stack):**

| Tier | Expected CTC |
| ---- | ------------ |
| Top-Tier (Microsoft, Amazon) | 18–28 LPA |
| High-Prob product (Chargebee, Razorpay, etc.) | 14–22 LPA |
| Hybrid (Nagarro, Publicis Sapient) | 10–16 LPA |

Don't reveal current CTC first. Say: "I'm targeting [X] based on market benchmarks for my experience and stack." Aim for a 50–80% hike. Counter the first offer by +10–15%. Never resign without an offer in hand.

## Part 8 — Don't Do This

- Don't wait until DSA feels "ready" to apply — apply from Day 1.
- Don't apply only to Top-Tier — High-Prob interviews are your reps.
- Don't rely only on Naukri — referrals convert ~5x better.
- Don't use all 5 portals equally — LinkedIn + Instahyre + Naukri only.
- Don't cold-apply when a referral path exists.
- Don't skip the tracker — follow-ups win offers.
