## 3. The Two-Track Preparation (Weeks 1–8)

You need to run two tracks in parallel:

### Track A: DSA + System Design (for interviews)

This is non-negotiable for product companies in India.

| Week | Focus                                          | What to Do                                                                         |
| ---- | ---------------------------------------------- | ---------------------------------------------------------------------------------- |
| 1–2  | Arrays, Strings, HashMap, Two Pointers         | Solve 30–40 LeetCode Easy/Medium. Do NeetCode 150                                 |
| 3–4  | Linked Lists, Stacks, Queues, Binary Trees     | 30 more problems. Focus on patterns, not memorization                              |
| 5–6  | Graphs, DP (basics), Sliding Window, BFS/DFS   | 20–25 Medium problems                                                             |
| 7–8  | Mock interviews + Low-Level Design (LLD)       | Practice on Pramp or with a friend. LLD: design a parking lot, URL shortener, etc. |

**Daily commitment:** 1.5–2 hours. Solve 2 problems/day minimum.

**Language:** Use C# for DSA — it differentiates you from the Java/Python crowd and aligns with your resume.

### Track B: Resume Distribution + Applications (start Week 1, don't wait for DSA)

| Channel                    | Action                                                                                                                                                          | Expected Response Rate |
| -------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------- |
| **Naukri**                 | Updated profile (done). Apply to 5–10 jobs/day. Set job alerts for ".NET Developer", "Software Engineer C#", "Full Stack Developer"                             | 3–5%                   |
| **LinkedIn**               | Turn on "Open to Work" (visible to recruiters only). Post 1 technical article/week about .NET or Azure                                                          | 5–8%                   |
| **Employee Referrals**     | **This is your highest-ROI channel.** Message 3–5 people/day on LinkedIn who work at your target companies. Use the referral template below                     | 15–25%                 |
| **Company Career Pages**   | Apply directly on careers.microsoft.com, freshworks.com/careers, etc.                                                                                           | 2–4%                   |
| **Instahyre / TopHire**    | Create profiles — these are recruiter-first platforms, good for 2–3 YOE                                                                                        | 5–10%                  |

### Referral message template:

> Hi [Name], I'm a Software Engineer with 2.5 years at GlobalLogic working on Microsoft projects — C# .NET Core, Azure, React/TypeScript. I'm exploring opportunities at [Company] and noticed you work there. Would you be open to referring me for [specific role ID/title]? Happy to share my resume. Thanks!

Short, specific, includes the role. Don't send a generic "I'm looking for opportunities."

## 4. Prepare Your "Story" (Critical for Interviews)

Every interviewer will ask: **"Why are you leaving your first company?"**

### Your answer (memorize a version of this):

> I've had a great 2.5 years at GlobalLogic building production systems for Microsoft — I've grown from a trainee to owning backend architecture, CI/CD pipelines, and shipping Azure Functions independently. Now I'm looking for a product-oriented environment where I can work on the core product, see direct user impact, and grow into system design ownership. [Company name]'s [specific product/mission] is exactly that kind of environment.

**Never say:** "I want better pay" / "I'm bored" / "Service companies are bad." Always frame it as **growing toward something**, not running from something.

## 5. Interview Rounds — What to Expect

| Round                           | What They Test                                | How to Prepare                                                                                     |
| ------------------------------- | --------------------------------------------- | -------------------------------------------------------------------------------------------------- |
| **Online Assessment**           | DSA, 2–3 problems, 60–90 min                  | LeetCode Medium. Practice under time pressure                                                      |
| **Technical Round 1**           | DSA + language fundamentals (C#, .NET)        | Know async/await internals, DI lifecycle, EF change tracking, middleware pipeline                  |
| **Technical Round 2 / LLD**    | Low-level design OR system design basics      | Design patterns (Repository, Factory, Strategy). Draw component diagrams                           |
| **Hiring Manager**              | Your projects, ownership, "why this company"  | Walk through your licensing analytics backend end-to-end in 5 minutes                              |
| **HR**                          | Compensation, notice period, culture fit      | Know your market rate (see below)                                                                  |

## 8. Common Mistakes to Avoid

| Mistake                                             | Why It Hurts                                                                  |
| --------------------------------------------------- | ----------------------------------------------------------------------------- |
| Waiting until DSA is "ready" before applying        | You'll never feel ready. Apply from Day 1 — interviews take 2–4 weeks to schedule anyway |
| Applying only to Tier 1                             | You need interview practice. Tier 3 interviews give you reps for Tier 1       |
| Ignoring referrals, relying only on Naukri          | Referrals convert 5x better than cold applications                            |
| Not negotiating offers                              | First offer is never the best offer. Always counter with +10–15%              |
| Resigning before getting an offer                   | Never resign without an offer letter in hand                                  |
