## 1. How Many Companies to Apply To

### Target Numbers (Weekly)

| Phase | Week | Power Platform | Frontend | Full Stack / Backend | Total/Week |
|-------|------|---------------|----------|----------------------|------------|
| **Warm-up** | 1–2 | 5 | 5 | 5 | ~15 |
| **Active** | 3–8 | 10 | 10 | 10 | ~30 |
| **Aggressive** | 9+ | 15 | 15 | 15 | ~45 |

- **Quality over mass-blast.** A tailored application beats 50 copy-paste applications every time. Aim for 80% tailored, 20% quick-apply.
- **Realistic conversion rate:** For every ~20–25 quality applications, expect 2–4 interview calls in India's market.
- **Do not apply to the same company for two different roles simultaneously** unless the JDs are clearly different departments. It signals desperation.
- **Tier your companies:**
  - **Tier 1 (Dream):** 20% of applications — FAANG-adjacent, top product companies, MNCs. Spend extra time tailoring.
  - **Tier 2 (Target):** 60% — Mid-size product companies, good service companies, startups with growth potential.
  - **Tier 3 (Safety):** 20% — Companies you'd take if nothing else comes through.

## 2. Segmenting Your Job Search by Role

Keep three role tracks completely separate. Never mix resumes or search configurations.

### Role Track Summary

| Track | Resume File | Keywords to Use | What to Highlight |
|-------|------------|-----------------|-------------------|
| **Power Platform** | `Resume_PowerPlatform.txt` | Power Apps, Power Automate, Power BI, Dataverse, SharePoint, Canvas Apps, Model-Driven Apps, Power Pages, PAC CLI | Automation flows, business process apps, SharePoint integration, governance |
| **Frontend** | `Resume_Frontend_Shadmaan.txt` | React, JavaScript, TypeScript, HTML, CSS, Tailwind, Redux, REST APIs, responsive design | UI/UX implementation, component libraries, performance, accessibility |
| **Full Stack / Backend** | `Resume_FullStack.txt` | Node.js, Express, MongoDB, PostgreSQL, REST API, GraphQL, CI/CD, Docker, system design | End-to-end ownership, API design, database schema, deployment |

### Segmentation Rules

- **Separate saved searches** on every platform — one per track. Name them clearly (e.g., "PP-Dev", "FE-Dev", "FS-Dev").
- **Separate cover letters / profile summaries** for each track — never use a generic one.
- **Never send the wrong resume.** Before applying, double-check: resume filename, summary line, and skills section match the role.
- If a JD spans two tracks (e.g., "React + Power Apps"), pick whichever track is 70%+ of the JD and apply with that resume.

## 4. Naukri — Profile Setup & Maintenance

### One-Time Profile Setup (Do This First)

1. **Headline:** Keep it role-specific. Since you're targeting 3 tracks, use a combined headline:
   > "Power Platform Developer | Frontend Developer (React) | Full Stack Developer | 2+ Years Experience"

2. **Summary:** Write 4–5 lines. Mention your tech stack clearly. Include: Power Apps, Power Automate, React, Node.js, JavaScript, TypeScript. End with what you're seeking.

3. **Key Skills Section:**
   - Add ALL relevant skills across all three tracks.
   - Naukri uses this for search ranking. Add: `Power Apps`, `Power Automate`, `Power BI`, `Canvas Apps`, `React.js`, `Node.js`, `JavaScript`, `TypeScript`, `REST API`, `MongoDB`, `SharePoint`, `Dataverse`.
   - Max out the skills count (Naukri allows up to 30).

4. **Work Experience:** For each role, use bullet points (not paragraphs). Start bullets with strong action verbs. Mirror language from JDs you're targeting.

5. **Projects:** Add 2–3 projects per track if possible. Mention tech stack, your role, and a measurable outcome.

6. **Education:** Keep it clean. Add CGPA only if 7.5+.

7. **Preferred Job Locations:** Set 3–4 cities. Add "Remote" explicitly if open to it.

8. **Expected Salary:** Research market rate for each role at your experience level. Set it 15–20% higher than your current CTC (or target CTC). Do not leave it blank.

9. **Profile Completeness:** Hit 100%. Naukri penalizes incomplete profiles in search rankings.

10. **Resume Upload:** Upload **one resume per track** using Naukri's multi-resume feature. Name them clearly:
    - `Shadmaan_PowerPlatform.pdf`
    - `Shadmaan_Frontend.pdf`
    - `Shadmaan_FullStack.pdf`

### Ongoing Maintenance (Weekly Must-Dos)

- **Profile freshness:** Naukri buries profiles that haven't been updated recently. **Every Sunday, log in and click "Modify Profile" → save without changing anything.** This refreshes your "last active" timestamp and boosts visibility in recruiter searches.
- **"Mark as Active":** Go to your profile settings and mark yourself as actively looking. Refresh this every 14 days — it expires.
- **Saved Searches:** Set up 3 saved searches (one per track) with email alerts set to "Daily Digest." Use filters:
  - Experience range (your actual range ± 1 year)
  - Salary: minimum expected
  - Location
  - Role: use exact keywords not just broad categories

### Naukri Daily Workflow

1. Open daily digest email → scan new jobs.
2. For each promising job: read JD → pick correct resume → apply with that resume.
3. Do **not** apply to everything with one click. Recruiter can see how many jobs you've applied to; mass-applying hurts credibility.
4. After applying, send a cold message to the hiring manager or HR on LinkedIn (see LinkedIn section).

## 5. LinkedIn — Profile Setup & Maintenance

### One-Time Profile Setup

1. **Photo:** Professional headshot. Light background. This alone can increase profile views by 14x.

2. **Banner:** Use a Canva banner that says your tech stack. E.g., "Power Platform | React | Node.js | Available for Opportunities."

3. **Headline (Most Important):**
   > Power Platform Developer | React & Full Stack Engineer | Building scalable apps & automations | Open to Work
   - Use the pipe `|` separator. Pack in keywords because LinkedIn's algorithm uses your headline for search.

4. **About Section (Summary):**
   - 3–4 short paragraphs.
   - Para 1: Who you are and what you build.
   - Para 2: Your Power Platform expertise.
   - Para 3: Your Frontend/Full Stack expertise.
   - Para 4: What you're looking for + call to action ("Open to roles in X. Let's connect!")
   - End with a list of skills: `Power Apps | Power Automate | React.js | Node.js | TypeScript | SharePoint | Dataverse | REST APIs | MongoDB`

5. **Experience Section:**
   - Add every role. Use bullet points. Include tools, scale, and outcomes.
   - For each role, LinkedIn lets you add media — add screenshots of dashboards, apps, or project repos.

6. **Skills Section:**
   - Add all skills. Prioritize getting endorsements for your top 5.
   - Reorder: put your strongest/most-targeted skills at the top.

7. **Open to Work:**
   - Enable the green "Open to Work" banner on your profile photo (for recruiters + public — use public if you don't have a current job to protect).
   - Go to: **Me → View Profile → Open to → Finding a new job**.
   - Fill in: all three job titles, locations, start date "Immediately," job types.

8. **Featured Section:**
   - Pin your best project (GitHub repo, live demo, or a post about something you built).

9. **Certifications:**
   - Add every Microsoft certification (PL-900, PL-100, PL-200, AZ-900 etc.), any Udemy/Coursera completions.
   - LinkedIn surfaces profiles with certifications more in recruiter filters.

### Ongoing Maintenance (Weekly)

- **Post once a week** — share a project, a learning, a tip about Power Platform or React. This builds topical authority. Recruiters actively check if you post; it signals engagement.
- **Comment on 3–5 posts daily** in your niche (Power Platform, React, tech hiring India) — this increases your profile visibility without you having to post original content.
- **Connect with 5–10 new people weekly:** Hiring managers, technical recruiters, and developers at target companies.
- **Send 3–5 cold outreach messages weekly** to HR/recruiters at target companies (template below).
- **Update your profile headline/about** whenever your job search focus shifts.

### Cold Outreach Template (LinkedIn)

> Hi [Name], I came across [Company] and I'm genuinely impressed by [something specific — product, recent news, tech stack]. I'm a [Power Platform / Frontend / Full Stack] developer with experience in [specific tool relevant to their stack]. I'd love to be considered for any relevant openings. I've attached my profile — happy to share my resume directly. Would really appreciate 5 minutes of your time.

Keep it short. Personalize the first line for every message. No generic spam.

### LinkedIn Daily Workflow

1. Check notifications — respond to any recruiter messages within 2 hours.
2. Open "Jobs" tab → check your 3 saved job alert searches (one per track).
3. Apply using "Easy Apply" only if you've already saved the right resume on LinkedIn per track.
4. For any company you apply to via Naukri or their website — find the hiring manager or HR on LinkedIn and send a short connection request with note.
5. Spend 5–10 minutes commenting on posts in your feed.

## 6. Other Platforms — How to Use Them

### Wellfound (AngelList)

1. Create a profile: fill in your role preferences (separate entries for each track), expected salary, preferred work type.
2. In the "What I'm Looking For" section, explicitly mention all three role types and your preferred stack.
3. Browse companies and apply directly from the platform. Startups often respond faster here than on Naukri.
4. Check "Open to" roles: full-time, contract, remote.

### Instahyre

1. Upload resume (use your FullStack resume as default — it's the most versatile).
2. Set your profile visibility to "Active."
3. You'll get shortlisted directly by companies. Respond to every shortlist within 24 hours.
4. Also proactively browse and click "I'm Interested" on roles that match.

### Cutshort

1. Complete the skill-assessment tests (React, JavaScript, Node.js) — higher scores = more visibility.
2. Set your role preference and salary expectations.
3. Companies will reach out, but also browse and apply manually 3x/week.

### Indeed India

1. Upload resume (use a generalized one or your FS resume).
2. Create email job alerts: one per role track, set to daily.
3. Indeed aggregates jobs from company career pages, so you may find roles not listed on Naukri.

### Hirist.com

1. Create a profile — it's tech-specific so recruiters here are usually more technical.
2. Tag yourself with Power Platform, React, Node.js skills.
3. Browse and apply 3x/week.

### GitHub (Passive but Powerful)

- Pin your best 4–6 repos. Each should have a proper README with screenshots and tech stack.
- Contribute to 1–2 open-source Power Platform or React projects — this signals genuine skill.
- Some companies actively source from GitHub. A clean profile with activity is a signal.

## 7. Daily & Weekly Routine

### Morning Block (45–60 min) — Every Weekday

| Time | Action |
|------|--------|
| 9:00 AM | Check email for Naukri/LinkedIn/Indeed digest alerts |
| 9:10 AM | Open LinkedIn → respond to recruiter messages, check job alerts |
| 9:30 AM | Apply to 3–5 jobs (Power Platform + Frontend + FS, balanced) |
| 9:50 AM | Send 1–2 LinkedIn cold outreach messages to HR/HMs at applied companies |

### Afternoon Block (30–45 min) — 3–4x/Week

| Time | Action |
|------|--------|
| 2:00 PM | Check Naukri, Cutshort, Hirist, Wellfound for new listings |
| 2:20 PM | Apply to 3–5 more jobs |
| 2:40 PM | Comment on 3–5 LinkedIn posts (topical: Power Platform, React, hiring) |

### Evening Block (30 min) — 2–3x/Week

| Time | Action |
|------|--------|
| 8:00 PM | Update job tracker (see Section 8) |
| 8:15 PM | Follow up on applications sent 5–7 days ago (via LinkedIn or email) |
| 8:30 PM | Prep for any interviews scheduled next day |

### Weekly Actions (Sunday — 60 min)

- [ ] Refresh Naukri profile (open and re-save to reset "last active" timestamp)
- [ ] Review tracker: move stalled applications to "No Response" after 10 days
- [ ] Review which track got most responses — allocate more effort there next week
- [ ] Write and post one LinkedIn post (tip, project update, learning)
- [ ] Connect with 5–10 new people on LinkedIn (recruiters, HMs, developers)
- [ ] Review and update saved searches if you're not seeing good results
- [ ] Calibrate: if apply count is high but calls are low, fix resume / keywords; if calls are high but no offers, fix interview prep

## 8. Tracking System

Use a simple spreadsheet (Google Sheets or Notion). Keep **one sheet per role track** with these columns:

| Column | What to Track |
|--------|--------------|
| Date Applied | DD/MM/YYYY |
| Company Name | — |
| Role Title | Exact JD title |
| Platform Used | Naukri / LinkedIn / Direct / etc. |
| Resume Version Sent | PP / FE / FS |
| JD Link | Save the URL (JDs get taken down) |
| Status | Applied → Shortlisted → Interview → Offer → Rejected → No Response |
| Follow-up Date | Date + 7 days from application date |
| Notes | Recruiter name, salary discussed, red flags |

### Status Flow

```
Applied
  ├── No Response (after 10 days) → Follow up once → Archive
  ├── Shortlisted → Interview Scheduled
  │     ├── Rejected (post interview) → Note feedback
  │     └── Offer → Evaluate
  └── Rejected (before interview) → Note reason if given
```

### Weekly Review Metrics (Track These)

- Applications sent this week (per track)
- Response rate % = (Shortlisted / Applied) × 100 — target > 15%
- Interview conversion % = (Interviews / Shortlisted) × 100 — target > 50%
- If response rate < 10%: resume or keyword problem
- If interview conversion < 30%: HR/screening stage issue (communication, salary, profile gap)
- If offer rate is low: technical interview prep issue → focus on InterviewPrepGuide
